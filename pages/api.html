2Schema

CREATE TABLE annotations (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  created_at   TEXT NOT NULL,
  updated_at   TEXT NOT NULL,
  author       TEXT NOT NULL DEFAULT 'anon',
  page         TEXT NOT NULL,
  anchor       TEXT,
  line_excerpt TEXT,
  type         TEXT NOT NULL CHECK(type IN ('comment','spec','precision')),
  comment      TEXT NOT NULL,
  status       TEXT NOT NULL DEFAULT 'open' CHECK(status IN ('open','addressed')),
  response     TEXT
);

POST body example:

{
  "page":    "/pages/index.html",
  "anchor":  "feat-types",
  "line_excerpt": "Three annotation types",
  "type":    "spec",
  "comment": "Route 'spec' annotations into the GitHub issue tracker"
}

4Deploy recipes

systemd user service

Drop ops/clickdoc.service into ~/.config/systemd/user/ and edit the WorkingDirectory + the CLICKDOC_PAGES_DIR env to point at your content. Then:

$ systemctl --user daemon-reload
$ systemctl --user enable --now clickdoc.service
$ systemctl --user status clickdoc.service

Auto-reload on file change

Pair the service with ops/clickdoc.path which uses systemd's PathChanged= directive to restart the service whenever your pages or static dir changes.

Caddy reverse proxy

example.com {
    encode zstd gzip
    reverse_proxy 127.0.0.1:8088
    log
}

Kubernetes Gateway API

Expose the service running on the host through an ExternalName Service + HTTPRoute. See ops/k8s/httproute.yaml in the repo.

Docker Compose

services:
  clickdoc:
    image: python:3.12-alpine
    working_dir: /app
    volumes:
      - ./:/app
      - ./content/pages:/content/pages:ro
      - clickdoc-data:/data
    environment:
      CLICKDOC_PAGES_DIR: /content/pages
      CLICKDOC_DB_PATH: /data/annotations.db
    command: python3 server.py
    ports: ["8088:8088"]
volumes:
  clickdoc-data: {}
